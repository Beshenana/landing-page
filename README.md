
# Landing Page — The Odin Project

A landing page built as part of The Odin Project Foundations curriculum.

## What I built

A fully responsive landing page using HTML and CSS only, following the Odin Project design spec.

## Sections

- Header with logo and nav links
- Hero section with heading, subtext and call to action button
- Info section with 4 feature cards
- Quote section
- Call to action banner
- Footer

## What I learned

- How to structure a page with semantic HTML
- Flexbox layout for nav, hero, cards and CTA
- External CSS and linking stylesheets
- Working with Google Fonts
- Following a design spec (colors, font sizes, weights)

## Images

Hero image and card icons are AI-generated using Microsoft Copilot.

## Built with

- HTML5
- CSS3 (Flexbox)
- Google Fonts — Roboto
